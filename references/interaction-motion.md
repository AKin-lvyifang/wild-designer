# 交互反馈与动效

用于 UI 方案、可编辑设计与可交互原型。下面列出的组件库是可选参考，不是默认要求；用户或项目已有明确规范、组件或偏好时按其选择；库名和源码不代表在当前环境已安装或已运行。

## 用途与边界

用户希望组件有反馈、内容变化有过渡。先让人看懂“能做什么、正在发生什么、结果是什么”，再用轻微动效表达过程。已有交互合同、项目组件和用户明确偏好优先；按当前交付选需要的部分，不给静态封面、PPT 配图机械加 UI 状态。

动效在已有 brief/styleContract 中按需记一行：**什么触发 → 哪个对象变化 → 怎么变化 → 最终状态与减少动态效果时怎样呈现**。例如“切换标签 → 内容区 → 旧内容退出、新内容轻微出现 → 保留当前标签，减少动态效果时直接换内容”。不为每个任务另建动效文档，不规定动画数量。

## 组件反馈

- **主操作立即有回应。** 按下、触摸或键盘激活时给清楚的反馈；异步操作进入真实的处理中状态，完成或失败后更新结果。动作执行与状态更新不等待装饰动画结束。
- **完成状态来自真实结果。** “已复制/已保存”、成功勾号、下载/上传完成必须绑定实际回执。Amicro 图库中的一些演示在 hover 时就切换成勾号或 Copied，这只能借视觉方式，不能直接当业务逻辑。
- **导航图标回应当前操作。** 保持静止时可识别，在悬停、键盘聚焦或激活时短暂回应；选中状态保持稳定，不靠持续晃动表达当前页面。页面变化来自真实导航结果，图标动了不等于已打开。
- **状态各有含义。** 默认、可交互、按下、聚焦、选中、禁用、处理中、成功和失败不要混为一个效果。键盘和触摸仍能看懂状态；命中范围和相邻排版保持稳定，不因图标替换、文案变化或悬停扩宽而跳动。
- **挑一个合适手法。** 普通按钮优先短促按压、明度变化或图标微动；磁吸、大范围转动、光扫、外扩环等只在当前方向和用途确有需要时选，不把图库的全部演出叠到主按钮上。

## 内容与状态过渡

- 标签切换、展开/收起、列表新增/删除、打开/关闭面板有清楚的来路与终点，变化对象与用户动作对应。退出、进入、留下的对象区别处理，避免整块内容一起闪烁。
- 同一内容只改变尺寸或位置时，优先连续调整；内容本身替换时再用轻淡入/淡出。不要把不同尺寸的新旧文字长时间叠在一起。
- 快速连续操作和返回时能接上当前状态，不跳回起点重播，不留重影或卡在中间；结果已到达时直接稳定呈现。
- 加载、空、失败状态使用真实文案；重试和返回保留应保留的输入与位置。已有项目状态规则照用，不因演示动效改变行为。

## 官网、发布页、展示页的滚动

- 需要滚动效果时，可优先考虑**隐约渐隐浮现**：进入阅读区域时以透明度变化为主，可配很轻的位移，保持内容安静、读起来连贯。效果强度以正常阅读速度下“能感到出现，又不被打断”为准。
- 按内容组呈现，顺着阅读顺序进入；进入阅读区逐渐清晰，离开阅读区可轻微淡出；回滚重新进入时平滑恢复。阅读区内不逐行消失，边界设稳定的过渡范围，避免来回一点就闪进闪出；减少动态效果时直接显示终态。
- 首屏关键内容、正文和主操作不必等一段动画播完才可用。页面刷新、跳转锚点或从中段进入时，当前位置内容直接正确呈现。
- 不因“需要滚动动效”自动增加长段固定、全屏强制滚动、视差、景深、大幅缩放或一镜到底。明确需要讲产品过程时，再选与当前目标相称的方式。
- 表格、后台、工具工作区和长文档优先保持操作与阅读即时响应；仅对本次实际变化的区域做必要过渡，不机械添加展示页演出。

## 减少动态效果与实际验收

- 尊重系统“减少动态效果”：关闭装饰位移、弹跳、连续旋转和滚动演出，所有内容直接到可读终态；状态反馈、操作结果、导航和功能仍然成立。不要因为动画被关掉留下透明或移出屏幕的内容。
- 不假设库已统一处理，采用时读具体组件；缺少减少动态效果支持时由现有宿主/封装补齐，并实际检查。
- 只检查当前改动涉及的状态：正常操作一次、返回/逆向一次，必要时快速连续操作；涉及异步结果则覆盖实际成功与失败。导航确认真实页面与选中态一致；按钮确认 hover 不冒充完成；内容切换确认位置、文字和布局稳定。
- 官网/展示页按正常速度滚到受影响区块再滚回；涉及窄屏时看同一处；打开减少动态效果后确认内容都在。沿用仍有效证据，不为动画重复跑固定次数的全套检查。
- 设计稿阶段可用状态帧或文字说明交代触发和终态，明确“动效建议/尚未运行”。**静态截图或生图不能证明真实动效已经实现、流畅或可操作。** 只有在可运行环境中实际观察相关过程后才报告通过；只读了代码就写“实现已核对，运行效果未验证”。

## 自动检查的适用范围

- 简单纯色背景能可靠推算时，按实际文字与背景检查对比度，极低对比也要报告，不因数值异常直接丢弃。图片、渐变或复杂叠层无法推算时标为“待视觉复核”，定位元素并查看相关截图，不能计入已通过。
- 按 brief/styleContract 中本次承诺的反馈与动效检查：有保存反馈不意味着必须有动画；承诺滚动展开才检查展开过程。没有动画要求的静态区域不算缺陷。
- 采集成功、规则检查、真实观察分别记录。报告已发现问题、已核对范围与未覆盖部分；不以进程退出码、最终一帧或零告警代替过渡与功能验收。
